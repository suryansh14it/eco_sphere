EcoSphere - Environmental Collaboration Platform
EcoSphere is a comprehensive platform that connects governments, NGOs, researchers, and communities to collaborate on environmental conservation projects.

🌿 Features
Multi-Role System: Dedicated dashboards for government agencies, NGOs, researchers, and community members
Project Management: Create, track, and manage environmental initiatives
XP & Rewards: Gamified system with EcoTokens to incentivize participation
Environmental Education: Quizzes, research papers, and educational content
Real-Time Monitoring: Track project progress, attendance, and impact metrics
Location-Based: GPS integration for project sites and issue reporting
Impact Tracking: Measure environmental metrics like CO₂ reduction and trees planted
Multilingual Support: Available in English, Hindi, Bengali, Tamil, and more

🛠️ Tech Stack
Frontend: Next.js 13 with TypeScript
UI Components: Tailwind CSS, shadcn/ui
Authentication: Custom auth system
Database: MongoDB
Blockchain: EcoToken smart contract (ERC20)
APIs: RESTful endpoints for all services

🚀 Getting Started
1. Clone the repository:git clone https://github.com/suryansh14it/eco_sphere.git
cd eco_sphere
2. Install dependencies: npm install 
3. Configure environment variables:cp .env.example .env.local
4. Start the development server: npm run dev
